# Scholenkaart Antwerpen

Alle scholen in de stad Antwerpen op de kaart, telling 1 februari 2026 (open data Onderwijs Vlaanderen), met
dynamische filters (onderwijs: niveau, graad, leerjaar, finaliteit, domein, studierichting of opleiding, onderwijsvorm,
fase OV3, type buitengewoon, duaal leren; gebied: onderwijszone, wijk), volledig scherm en export naar PowerPoint en Word.

`index.html` is één bestand dat ook offline werkt. Het wordt gebouwd in roodrood/onderwijsanalyse-agso met
`python scripts/scholenkaart/bouw.py` (uitvoer `andere-oefeningen/scholenkaart.html`) en hier als `index.html` gezet.
Ingebouwde bibliotheken: PptxGenJS (MIT), docx (MIT), lettertype Source Sans 3 (SIL OFL).
